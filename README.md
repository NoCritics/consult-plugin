## Features

- **Ask and chat:** one question or a multi-turn chat, with files and images.
- **Council:** several models answer, then rank each other's answers without seeing who wrote which.
- **Images:** generated by Antigravity, or by GPT through Codex.
- **Background tasks:** hand work to Codex, agy, opencode (free cloud models) or a local model while you keep going. Each worker is fenced to the task's folder; in a git project its edits come back as a copy that Claude merges.
- **Local models:** llama-swap, Ollama, LM Studio, llama-server or any OpenAI-compatible server, set up by `/consult:setlocal`.
- **In Claude Code:** a live row above the prompt for each call, and a `/consult` pane with answers, local models and tasks.

## Install

Needs Node.js 20 or newer. In Claude Code:

```
/plugin marketplace add NoCritics/consult-plugin
/plugin install consult@nocritics
```

Restart Claude Code, then sign in to the providers you want: `codex login`, run `agy` once, install opencode 2.x (by default it runs inside Codex's sandbox, so Codex must be installed too), or start a local runner and run `/consult:setlocal`. Claude Desktop installs the `.mcpb` from the [releases page](https://github.com/NoCritics/consult-plugin/releases).

## Use

Ask in plain words: "get a second opinion on this", "ask codex why this test fails", "run the council on this", "make an image of a lighthouse at dusk", "have opencode review src/". Or use the slash commands: `/consult:codex`, `/consult:agy`, `/consult:local`, `/consult:council`, `/consult:chat`, `/consult:delegate`.
